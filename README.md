# 🎮 Calculadora de Partidas Rankeadas

Este projeto foi criado como parte de um desafio prático da DIO. Ele simula a classificação de um jogador com base na quantidade de vitórias e derrotas em partidas ranqueadas.

## 🧾 Descrição

A função `calcularRankeadas(vitorias, derrotas)` calcula o **saldo de vitórias** e determina o **nível** do jogador com base nas seguintes regras:

| Vitórias           | Nível      |
|--------------------|------------|
| Menor que 10       | Ferro      |
| 11 a 20            | Bronze     |
| 21 a 50            | Prata      |
| 51 a 80            | Ouro       |
| 81 a 90            | Diamante   |
| 91 a 100           | Lendário   |
| 101 ou mais        | Imortal    |

A saída exibida será:
> O Herói tem de saldo de **{saldoVitorias}** está no nível de **{nivel}**
